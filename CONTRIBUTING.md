# Contributing

Written from Apple's, Google's and the platform vendors' public documentation.
Do not paste code from other attribution SDKs.

This package is a thin wrapper. The attribution logic lives in the native SDKs,
[fload-attribution-ios](https://github.com/fload-ai/fload-attribution-ios) and
[fload-attribution-android](https://github.com/fload-ai/fload-attribution-android).
A change to what is captured or sent belongs there, not here.

Security issues: report them privately through this repository's Security tab
(Report a vulnerability), not in a public issue.
